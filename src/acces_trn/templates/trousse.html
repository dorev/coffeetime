Trousse d'intégration pour les diffuseur·euse·s

Ajoute un accès direct aux TRN dans ta communauté. Tout se met à jour automatiquement selon la disponibilité de l'équipe. Remplace {{ src }} par le nom de ta chaîne pour qu'on sache d'où viennent les visites (aucune donnée personnelle n'est recueillie).

1. Lien officiel

{{ base_url }}/?src={{ src }}

À mettre dans ta bio Twitch, tes panneaux, ton Discord, tes réseaux sociaux.

2. Commande !trn dans le chat Twitch

Le bot répond selon le statut, par exemple : « 🟢 Un·e TRN est disponible maintenant… ».

Nightbot

!addcom !trn $(urlfetch {{ base_url }}/status.txt?src={{ src }})

StreamElements

!command add !trn ${customapi.{{ base_url }}/status.txt?src={{ src }}}

Fossabot

$(customapi {{ base_url }}/status.txt?src={{ src }})

Astuce : ajoute aussi un alias !aide qui affiche la même chose.

3. Widget pour un site Web

<iframe src="{{ base_url }}/widget?src={{ src }}" title="Parler à un·e TRN"
        style="border:0;width:340px;height:64px"></iframe>

4. Incrustation OBS (source navigateur)

{{ base_url }}/widget?src={{ src }}&theme=overlay

Largeur 340, hauteur 64. Le statut se met à jour toutes les minutes.

5. Badge image

<a href="{{ base_url }}/?src={{ src }}"><img src="{{ base_url }}/badge.svg" alt="Statut TRN"></a>
